# POWERSHIFT : site du projet

Site vitrine en anglais du projet de recherche POWERSHIFT : comprendre et déplacer le
pouvoir dans la conservation de la biodiversité.

Le site présente le cadre d'analyse, les quatre axes de recherche, le Theory of Change,
les terrains (Indonésie, Italie, Tanzanie) et les réseaux partenaires.

Projet financé par Biodiversa+ (appel BiodivTransform).

Site one-page statique (`docs/index.html`), sans dépendance lourde, déployé sur GitHub
Pages.
